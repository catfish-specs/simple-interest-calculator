# simple-interest-calculator
Project Description

The Simple Interest Calculator is a Bash-based calculator that computes simple interest using the principal amount, rate of interest, and time period provided by the user.

Formula

Simple Interest = (Principal × Rate × Time) / 100

Where:

Principal = Initial amount of money
Rate = Rate of interest per year
Time = Time period in years
Features
Accepts principal amount as user input
Accepts rate of interest as user input
Accepts time period as user input
Calculates simple interest
Displays the calculated simple interest
Technology Used
Bash Shell Script
Git
GitHub
How to Run

Run the following command in the terminal:

bash simple-interest.sh

The program will ask the user to enter the principal, rate of interest, and time period, and then display the simple interest.
